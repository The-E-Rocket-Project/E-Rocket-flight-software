# `include/erocket/` — Shared Headers

Header-only components (controllers, allocator, aggregators) and shared types consumed by all nodes under `src/`.

---

## Top-level headers

### `constants.hpp`

Declares `namespace erocket::constants` with constexpr strings for every ROS 2 parameter name and topic used system-wide. Organised into sub-namespaces:

| Namespace | Contents |
|-----------|----------|
| `constants::vehicle` | `offboard.vehicle.*` parameters — servo/motor active flags, max tilt, thrust curve, torque curve |
| `constants::controller` | Topic names (`/fmu/in/*`, `/fmu/out/*`, `/offboard/*/debug`) + PID gain param names |
| `constants::controller_generic` | Generic controller frequency parameter |
| `constants::flight_mode` | Flight mode topics (`get`/`set`) + `offboard.flight_mode` parameter |
| `constants::mocap_forwarder` | Mocap topic `/mocap/pose_enu/erocket` + active flag |
| `constants::setpoint` | Setpoint topics and parameters |
| `constants::takeoff_landing` | Takeoff/landing duration and height parameters |
| `constants::emergency` | `/fmu/out/actuator_armed` topic |

### `frame_transforms.h`

Public API for the frame transforms library. See [`src/lib/README.md`](../../src/lib/README.md) for full documentation. Summary:

- **`EulerAngle`** struct and unit conversion inlines (`radians_to_degrees`, `degrees_to_radians` for scalar, `Vector3d`, `EulerAngle`)
- **`quaternion_to_euler_radians`** / `euler_radians_to_quaternion` (custom Wikipedia formula — Eigen's built-in didn't work)
- **Static frame transforms**: `transform_static_frame(vec, StaticTF)` for `ENU↔NED`, `AIRCRAFT↔BASELINK`, `ECEF↔ENU` — with `Covariance3d/6d/9d` overloads
- **Dynamic frame transforms**: `transform_frame(vec, q)` / `transform_frame(cov, q)`
- **Convenience templates**: `ros_to_px4_orientation`, `px4_to_ros_orientation`, `ned_to_enu_local_frame`, etc.
- **`namespace utils::quaternion`**: Eigen ↔ array conversion, yaw extraction
- **`namespace utils::types`**: Covariance matrix ↔ flat array conversion templates
- **Static constants**: `NED_ENU_Q`, `AIRCRAFT_BASELINK_Q`, `NED_ENU_REFLECTION_XY`, `NED_ENU_REFLECTION_Z`

### `vehicle_constants.hpp`

`class VehicleConstants` — reads all `offboard.*` physical parameters from the ROS 2 parameter server at construction:

| Field | Parameter |
|-------|-----------|
| `mass_of_system_` | `offboard.mass_of_system` |
| `lever_arm_` | `offboard.lever_arm` |
| `gravitational_acceleration_` | `offboard.gravitational_acceleration` |
| `moment_of_inertia_` | `offboard.moment_of_inertia` |
| `servo_active_` | `offboard.vehicle.servo_active` |
| `motor_active_` | `offboard.vehicle.motor_active` |
| `servo_max_tilt_angle_degrees_` | `offboard.vehicle.servo_max_tilt_angle_degrees` |
| `default_motor_pwm_` | `offboard.vehicle.default_motor_pwm` |
| `max_motor_pwm_` | `offboard.vehicle.motor_max_pwm` |
| `motor_thrust_curve_m_` / `_b_` | `offboard.vehicle.motor_thrust_curve.{m,b}` |
| `delta_torque_a_` / `_b_` / `_c_` | `offboard.vehicle.delta_torque.{a,b,c}` |

Throws `std::runtime_error` if any required parameter is missing or out of range.

### `emergency_switch.h`

`class EmergencySwitch` — subscribes to `/fmu/out/actuator_armed` and monitors `manual_lockdown` flag (set by the RC radio kill switch on PX4).

- `emergency_switch_on()` returns `true` once triggered
- Consumed by `mission.cpp` in the 100 Hz fast loop — triggers `FlightMode::ABORT`

### `setpoints.h`

Compile-time trajectory data generated by `trajectory/csv_to_header_with_transform_to_ned.py`. A C array `Setpoints[][10]` with columns: `t, x, dx, ddx, y, dy, ddy, z, dz, ddz`. Included by `mission.cpp` via `#include "setpoints.h"` inside the fast loop body (scoped to `IN_MISSION` case).

## `controller/` — Control Pipeline Headers

### `controller/state.hpp`

**`struct State`** — Aggregated vehicle state combining raw PX4 messages with derived Eigen vectors:

| Field | Source |
|-------|--------|
| `attitude` | Raw `VehicleAttitude` message |
| `angular_velocity` | Raw `VehicleAngularVelocity` message |
| `local_position` | Raw `VehicleLocalPosition` message |
| `odometry` | Raw `VehicleOdometry` message |
| `quaternion` | From `VehicleAttitude.q` |
| `rotation_matrix` | `q.toRotationMatrix()` |
| `euler_angles` | Via `quaternion_to_euler_radians` |
| `angular_rate` | From `VehicleAngularVelocity.xyz` |
| `position`, `velocity`, `acceleration` | From `VehicleLocalPosition.{x,y,z,vx,vy,vz,ax,ay,az}` |

**`class StateAggregator`** — Subscribes to four `/fmu/out/*` topics and updates a shared `State` struct on each callback. Provides `get_state()` for the controller timer callbacks to read from.

### `controller/setpoint.hpp`

**`struct PositionSetpoint`** — `{position, velocity, acceleration, jerk, snap, yaw, yaw_rate, yaw_acceleration}`

> [!NOTE]
>`jerk` and `snap` correspond to the 3rd and 4th derivatives of the position.

**`struct AttitudeSetpoint`** — `{attitude[3]}` (roll, pitch, yaw in radians)

**`class SetpointAggregator`** — Subscribes to three topics:

| Topic | Type | Behaviour |
|-------|------|-----------|
| `offboard/setpoint_c5_meters` | `SetpointC5` | Full C5 trajectory: maps all fields, extracts yaw |
| `offboard/attitude_setpoint_degrees` | `Vector3Stamped` | Validates range ±90° roll/pitch, ±180° yaw, rejects NaN |
| `offboard/translation_position_setpoint_meters` | `Vector3Stamped` | **Adds** to current position setpoint, zeros velocity/acceleration |

Provides `get_position_setpoint()`, `get_attitude_setpoint()`, and `set_attitude_setpoint()` (used by the position controller to override the attitude target).

### `controller/allocator.hpp`

**`struct AllocatorInput`** — `{thrust_vector (Vector3d), tau_delta_bar (double)}`

**`struct AllocatorOutput`** — `{inner_servo_pwm, outer_servo_pwm, upwards_motor_pwm, downwards_motor_pwm}`

**`class Allocator`** — Maps mathematical forces/torques to physical PWM signals:

| Step | Operation |
|------|-----------|
| Thrust magnitude | `thrust_ = thrust_vector.norm()` |
| Base PWM | `M_bar_ = newtons_to_pwm(thrust_)` (inverse of thrust curve) |
| Differential PWM | `M_delta_ = (tau_delta_bar - b·M_bar - c) / a` |
| Servo inner | `gamma_inner_ = asin(thrust_vector.y / thrust_)` |
| Servo outer | `gamma_outer_ = asin(-thrust_vector.x / sqrt(thrust² - thrust_vector.y²))` |
| Output limiting | Servos clamped to `±1.0`, motors to `[0, max_motor_pwm]` |

**Special modes:**
- `compute_allocation_neutral()` — zeros servos, sets motors to `NAN` (disarmed)
- `indirect_actuation()` — bypasses PID loops, sets angles/PWMs directly (used during ARM wiggle test)

**Safety flags** (from `VehicleConstants`):
- `servo_active_` = false → servos output 0
- `motor_active_` = false → motors output `NAN` (disarmed by PX4)

At construction, publishes zero PWM for 1 second to initialise the actuators.

**Publishes to:** `/fmu/in/actuator_servos`, `/fmu/in/actuator_motors`, `/offboard/allocator/debug`

### `controller/impls/` — Controller Implementations

#### `impls/attitude_pid.hpp`

**`class AttitudePIDController`** — Inner loop. Runs the PID formula on each timer tick:

```
error = setpoint.attitude - state.euler_angles
integrated_error += error * dt
tau_bar = k_p·error + k_d·(-angular_rate) + k_i·integrated_error
```

For each axis where `controller_active[i]` is false, `tau_bar[i]` is zeroed (I-term for roll and pitch is disabled in `offboard.yaml`: `k_i: [0.0, 0.0, 0.5]`).

Converts torques to thrust vector:
```
thrust_vector.x = (I / L) · tau_bar.y
thrust_vector.y = -(I / L) · tau_bar.x
thrust_vector.z = u3
tau_delta_bar = tau_bar.z
```

**Publishes to:** `/offboard/attitude_controller/debug`

#### `impls/position_pid.hpp`

**`class PositionPIDController`** — Outer loop. Computes desired acceleration from position/velocity tracking error:

```
error_p = setpoint.position - state.position
error_d = setpoint.velocity - state.velocity
error_i += k_i·error_p·dt
output = k_p·error_p + k_d·error_d + error_i + k_ff·feed_forward_ref
```

The output is saturated per-axis (`min_output`, `max_output` from config), then gravity is subtracted from the Z component. Desired attitude is computed from the desired acceleration vector using rotation matrix decomposition, saturated to `±30°` for roll and pitch.

**Returns:** `PositionPIDControllerOutput{desired_acceleration, desired_attitude, u3}` where `u3 = mass × norm(desired_acceleration)`.

**Note:** The position controller requires all three attitude controllers to be active — enforced at construction in `baseline_pid_controller.cpp`.

**Publishes to:** `/offboard/position_controller/debug`

#### `impls/generic_controller.hpp`

**`class GenericController`** — Stub/template for implementing custom control algorithms. The `compute()` method currently reads state + setpoint from aggregators and returns a zero-filled `AllocatorInput`. User-implemented logic goes inside this method.

**Publishes to:** `generic_controller/debug`

## `mission/` — Trajectory Generation

### `mission/take_off_and_landing.hpp`

**`struct Trajectory`** — `{pd, pd_dot, pd_2dot, pd_3dot, pd_4dot}` (position through snap).

**`compute_takeoff(t, p0, hd, ts)`** — Cosine smooth climb:
- For `t ≤ ts`: `z = p0.z - (hd/2)·(1 - cos(π·t/ts))`
- For `t > ts`: hover at `p0.z - hd`
- Higher-order derivatives computed analytically

**`compute_landing(t, p0L, ground_p0, td)`** — Cosine smooth descent:
- Descends from hover position `p0L` toward `ground_p0.z` over `td` seconds
- Same cosine profile as takeoff but inverted
- After `td`: set position to ground level, zero all derivatives

Both functions are `inline` and header-only, called by `mission.cpp` in the 100 Hz fast loop.
